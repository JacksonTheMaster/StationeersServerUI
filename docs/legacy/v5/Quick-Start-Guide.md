## 🚀 TL;DR for the impatient & _God tier_ Admins

1. 📦 Download latest executable from the [![Download latest Version](https://img.shields.io/badge/Download-Page%20-orange?style=for-the-badge)](https://ssui.dev/) or the [Github Releases page](https://github.com/JacksonTheMaster/StationeersServerUI/releases)
2. 📁 Place in empty folder and run it (`chmod +x` on linux)
3. 👁️ Read and follow the on-screen instructions.
4. 🌐 Access UI at `https://<<server-ip>>:8443` for a simple initial setup track.
5. 🎮 Configure and start your server through the web interface
6. 🎆Functioning Stationeers Server on localhost - within 2-5 minutes (mileage may vary)

<details>
<summary>Linux considerations </summary>
Linux dependencies for steamcmd (glibc) will be installed automatically. Might need to authenticate. SSUI is built with [Go](https://go.dev/), so SSUI does **not** have any external dependencies, you simply need the executable.
</details>

<details>
<summary>Windows considerations</summary>
The Stationeers Server on Windows requires the 

[Visual C++ Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170) 

Depending on your Windows version, automatically installed by the Stationeers Server. 
`Just install it manually to be sure.` It can be Downloaded from the above link.
</details>

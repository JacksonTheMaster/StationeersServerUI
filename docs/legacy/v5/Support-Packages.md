## How to generate a support package

<img width="702" height="251" alt="image" src="https://github.com/user-attachments/assets/8078589f-8c3d-4446-88b0-1fce345f1854" />

!!! important
    The commands `sm` & `sp` are NOT supposed to go into the console on the WebUI

1: start SSUI if not done already

2: run `sm` in the **SSUICLI** (terminal console that opens when you start SSUI) 

3: reproduce the issue as best as you can

4: type `sp` into SSUICLI to generate a support package

5: type `sm` again to **disable** support mode again

6: create a ticket on the SSUI Discord if not done already

6: drop the support package zip **that was created and saved to the server directory** into the ticket

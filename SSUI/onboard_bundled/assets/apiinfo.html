SSUI

Stationeers Server UI

API v3

One versioned API, one response shape, and explicit permissions for every operation.

Back to SSUI

Response format

JSON endpoints return exactly one of these envelopes:

{"data":{"running":true}}
{"error":{"code":"forbidden","message":"Permission denied"}}

Downloads return the requested file and stream endpoints use text/event-stream.

Authentication

Authentication is mandatory in v6. Browser logins create an HttpOnly SSUISession cookie. State-changing browser requests also require the value of the SSUICSRF cookie in the X-SSUI-CSRF header.

Automations use personal access tokens as Authorization: Bearer ssui_pat_.... A token only receives the scopes selected when it is created. Old JWT API keys are not migrated.

POST /api/v3/auth/login
Content-Type: application/json

{"username":"admin","password":"your password"}

First start

If no v5 users can be migrated, SSUI prints a short-lived setup secret in the terminal. Enter it on the setup page with the first owner username and password. Existing human users are migrated as owners; old API keys and sessions are discarded.

Identity

GET/api/v3 API capabilities and granted permissions

GET/api/v3/auth/session Current session and user

POST/api/v3/auth/login Create a browser session

POST/api/v3/auth/logout Revoke the browser session

GET/api/v3/auth/users List users

POST/api/v3/auth/users Create a user

PATCH/api/v3/auth/users/{id} Update a user

DELETE/api/v3/auth/users/{id} Delete a user

GET/api/v3/auth/groups List groups and permissions

POST/api/v3/auth/groups Create a group

PUT/api/v3/auth/groups/{id} Replace a group

DELETE/api/v3/auth/groups/{id} Delete a group

GET/api/v3/auth/tokens List visible tokens

POST/api/v3/auth/tokens Create a scoped token

DELETE/api/v3/auth/tokens/{id} Revoke a token

GET/api/v3/auth/sessions List visible sessions

DELETE/api/v3/auth/sessions/{id} Revoke a session

GET/api/v3/auth/audit Read the security audit log

Server and backups

GET/api/v3/server/status Server state and uptime

GET/api/v3/server/players Connected players

POST/api/v3/server/start Start the server

POST/api/v3/server/stop Stop the server

GET/api/v3/backups List archives by stable filename

GET/api/v3/backups/analysis?name=FILE.save Read or run save analysis

POST/api/v3/backups/restore Restore the archive named by {"name":"FILE.save"}

GET/api/v3/backups/download?name=FILE.save Stream an archive

Configuration and tools

PATCH/api/v3/settings Update selected settings

GET/api/v3/worldgen/catalog World generation choices

POST/api/v3/backend/reload Reload managed components

GET/api/v3/update Read update availability

POST/api/v3/update Check for or apply an update

GET/api/v3/detections List custom detections

POST/api/v3/detections Create a custom detection

DELETE/api/v3/detections/{id} Delete a custom detection

POST/api/v3/sscm/commands Send an SSCM command

POST/api/v3/steamcmd/run Update the game installation

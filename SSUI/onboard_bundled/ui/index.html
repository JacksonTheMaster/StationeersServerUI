      ℹ️ Transitioning to SteamServerUI (click to expand)

      StationeersServerUI (V5) is slowly evolving into SteamServerUI (V6) - a modern, multi-game server management tool that supports any Steam game while keeping Stationeers at its core.

      ℹ️ Sit back and relax: If you have auto updates enabled, you'll get notified and guided once V6 is ready. Current plan: End of Q42026, StationeersServerUI will get LTS until further notice. You can check the Migration Guide to plan your transition.

      Why are we doing this? StationeersServerUI has been great for Stationeers servers with its one-click setups, Discord bots, and smart backups. However, its Stationeers-only focus and retro, hard-to-maintain frontend code limited its potential. SteamServerUI uses the same reliable Go backend but adds a modern Svelte-based UI, desktop app, and flexible system supporting any Steam game - from Satisfactory to Project Zomboid and beyond.

      What's changing: V6 features a sleek new interface, universal Steam game support, and enhanced reliability. You're gaining a future-proof tool that's easier to use and can grow with you.

      Timeline: A Stable SteamServerUI release planned for Q4-2026. Christmas, probably. StationeersServerUI will continue receiving long time support updates until Q42026. See the Roadmap here for more details.
